# java-calculator-precourse

## 구현할 목록 목록 - 문자열 덧셈 계산기

### 입력 기능
- [x] 구분자와 양수로 구성된 문자열을 입력받는다.
    - 잘못된 값을 입력한 경우 예외를 발생시킨다.

### 핵심 기능

- [x] 입력된 문자열을 쉼표(,) 또는 콜론(:) 구분자로 분리한다.
- [x] 커스텀 구분자는 문자열 앞부분의 "//"와 "\n" 사이에 위치하는 문자를 커스텀 구분자로 사용한다.
    - 커스텀 구분자는 1글자 이상일 수 있다. 예시) //;.\n1;2;3 이 경우 ;.가 커스텀 구분자이다
- [ ] 구분자를 기준으로 분리한 숫자의 합을 반환한다.
- [ ] 빈 문자열을 입력 할 경우 0으로 반환시킨다.
- [ ] 사용자가 잘못된 값을 입력할 경우 ```IllegalArgumentException``` 를 발생시키고 애플리케이션을 종료시킨다.

### 출력 기능

- [x] 덧셈할 문자열을 입력해 주세요. 문구열 출력
- [ ] 계산에 대한 결과 출력

### 예외 처리
- [x] 입력 칸에 빈칸이 있을경우 예외처리
- [ ] 기본 구분자 사용시 다른문자 넣을경우 예외처리 
- [ ] 커스텀 구분자 사용시 "//" 와 "\n" 사이에 입력하지않은 경우.
- [ ] 커스텀 구분자 입력 시작시 "//" 를 먼저 입력하지 않은 경우.
